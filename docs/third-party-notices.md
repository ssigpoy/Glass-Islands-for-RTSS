# 第三方素材与许可

- CPU、显卡、仪表、显存图标取自 **HeyOkay 的 Slick Overlay for RTSS**，在本项目中重新裁切、缩放和着色。保留 [MIT 许可原文](../licenses/LICENSE-Slick-Overlay.txt)。[项目与素材来源](https://github.com/HeyOkay/Slick-Overlay-for-RTSS)
- 普通岛的基础渐变来自 **Faisal 的 Apple-Style RTSS Overlays 2.0**，使用 Laptop Minibar 的 Smoke 背景，调整了尺寸、圆角、染色和边缘光。保留 [MIT 许可原文](../licenses/LICENSE-Apple-Style-RTSS.txt)。[发布包来源](https://github.com/realHfde/Apple-Style-Inspired-RTSS-Overlay/releases/tag/v2.0)
- **Adderley Bold** 由 gorohovskiy / Dharma Type 提供。本包附上 Slick Overlay 项目中未经修改的字体文件及 [SIL Open Font License 1.1](../fonts/OFL.txt)。[字体分发目录](https://github.com/HeyOkay/Slick-Overlay-for-RTSS/tree/main/fonts/Adderley)

本仓库是社区自定义布局。RTSS 与 OverlayEditor 由各自的发布方分发，仓库中的许可证文件适用于上面列出的第三方素材。
